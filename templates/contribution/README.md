# Contribution template

This is a starter package, not a runnable Perception scenario. Copy it into one
content category, replace the manifest values, add real artifacts, and replace
this README with the sections below.

## Purpose

Describe the scenario, intended users, and expected results.

## Prerequisites and permissions

Identify the API entry point, authentication method, required access, dependencies,
and tenant/workspace prerequisites.

## Inputs

Document every input, required/optional status, format, validation, and sanitized
examples. Keep this section consistent with `manifest.json`.

## Deployment or setup

Provide exact steps and explain resource changes and costs.

## Usage and verification

Provide an example and describe how users recognize successful execution.

## Cleanup

Explain resource removal and access revocation.

## Tests and limitations

Document tests, runtime input validation, supported environments, and limitations.
